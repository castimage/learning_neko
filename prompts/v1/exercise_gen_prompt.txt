## RULES
- 每个大纲分节至少出题一道，分值权重与该节在资料中的篇幅占比一致。
- 题目总体难度与学习者水平匹配，其中约三成题目用于区分较高水平。
- 题干必须自足：不得出现「如上文所述」「参见第几节」这类需要回看正文才能作答的表述。
- 选择题至少给出三个选项，且只有一个正确；只有两个合理选项时请改为填空题（options 返回空数组），不要编造牵强的干扰项。
- 每题的 answer 必须唯一确定，不得出现「以上都对」这类选项。
- 解析需要说明正确项为何正确，并指出最容易误选的干扰项错在哪里。
- 考点不得超出资料正文范围。
- 题目要配图时先分清两类来源：能由坐标轴与曲线表达清楚的示意图（diagram）、以及随时间变化的动画（animation），这两类由你直接给出绘制规格；真实图片、音频与视频（image/audio/video）只能引用 available_assets 中列出的 key。
- 引用素材时 asset_key 必须逐字取自 available_assets；diagram 与 animation 的 asset_key 一律返回空字符串，并且不要同时给出另一种规格。
- 素材要挂在某道题上时，就把该素材写进这道题自己的 media 数组，并在题干或解析里写 ![图注](media:<id>) 占位符；不要跨题共用编号。
- 与题干无关的素材不要挂；题干依赖素材时，学习者不看资料正文也应能读懂题目。

输出为 JSON 对象，字段含义与取值要求如下：
- exercises：对象数组，每个元素含：
  - q_id：字符串，题目编号，形如 q-1，按出题顺序连续编号。
  - question：字符串，题干。
  - options：字符串数组，单选题给出恰好四个选项；填空题返回空数组。
  - answer：字符串，正确答案；单选题填选项原文，填空题填标准答案。
  - analysis：字符串，解析，需说明正确原因并点名最易误选的干扰项。
  - knowledge_point：字符串，该题对应的知识点，取值必须来自 knowledge_points 集合中的某一项，不得自造。
  - difficulty：字符串，取值只能是「基础」「进阶」之一。
  - media：对象数组，该题挂载的素材，没有就返回空数组。每个元素含：
    - id：字符串，素材编号，在该题的 media 内唯一，供题干与解析里的 ![图注](media:<id>) 占位符引用。
    - kind：字符串，取值只能是 "diagram"、"animation"、"image"、"audio"、"video" 之一。
    - caption：字符串，该素材的图注；引用类素材必填。
    - alt：字符串，替代文本，供无法渲染时兜底。
    - asset_key：字符串；kind 为 image/audio/video 时必填且必须逐字取自 available_assets，kind 为 diagram/animation 时留空字符串。
    - diagram：对象或 null；仅当 kind 为 "diagram" 时给出，含 title、axis（x_label、y_label、x_min、x_max、y_min、y_max，且 x_min < x_max、y_min < y_max）、series（对象数组，元素含 id、label、style（"solid"/"dashed"/"dotted"）、points（对象数组，元素含 x 与 y，至少两个点））、marks（对象数组，元素含 text、x、y，可为空数组）。
    - animation：对象或 null；仅当 kind 为 "animation" 时给出，含 title、axis（结构同 diagram.axis）、tracks（对象数组，元素含 id、label）、frames（对象数组，至少两帧且 t 严格递增，元素含 t 与 samples（对象数组，元素含 track_id 与 value；每条 track 在每一帧都要有 sample））、playback（含 duration_ms、fps（1 到 60）、loop、autoplay）、marks（结构同 diagram.marks，可为空数组）。

## EXAMPLES
一道合格的单选题目应形如：
- q_id：q-1
- question：关于学习率过大对训练过程的影响，下列说法正确的是？
- options：["损失函数单调下降，收敛更快", "参数更新步长过大，损失在最优值附近震荡", "模型容量增大，容易过拟合", "梯度消失，参数几乎不更新"]
- answer：参数更新步长过大，损失在最优值附近震荡
- analysis：学习率直接乘在梯度上决定步长，过大会让参数越过最优值并在其两侧反复跳动。选项一方向相反，选项三与学习率无关，选项四是学习率过小或深层网络梯度问题，均非本题考点。
- knowledge_point：学习率
- difficulty：基础
- media：[]

一道需要看图的题目则应形如（题干里写 `观察下图，下列说法正确的是？![损失曲线](media:m1)`）：
- media：[{"id": "m1", "kind": "diagram", "caption": "损失曲线", "alt": "一条先下降后上升的曲线", "asset_key": "", "diagram": {"title": "损失随轮次的变化", "axis": {"x_label": "训练轮次", "y_label": "损失", "x_min": 0, "x_max": 10, "y_min": 0, "y_max": 5}, "series": [{"id": "s1", "label": "损失", "style": "solid", "points": [{"x": 0, "y": 5}, {"x": 5, "y": 1}, {"x": 10, "y": 4}]}], "marks": []}, "animation": null}]
